# Project Overview
A tic-tac-toe game built with React, based on the official React tutorial and extended with a scoreboard and a Restart button for starting a new game.

## How to run it

In terminal, write command:

```bash
npm install
npm start
```


## My contribution

Besides React Tic-Tac-Toe tutorial, I added:

- **Restart button:** clears the board and the move history.
- **Scoreboard:** to show how many games X and O have won.
- **Reset scores button:** sets both scores back to 0.

## What I learned

One challenge I faced was understanding how React state works. At first, I found it confusing to under stand the relationship between usestate and variable in Read. I spent time reading the tutorial until I fully understood how state keep track of updates after each click. Once I understand how separated the game state from the score state, adding features like restart and score tracking became much easier.
